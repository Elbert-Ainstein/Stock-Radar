## 2026-06-26 — Structural memory-bull thesis (memory node: MU, SNDK)

Hume's standing view: **memory is structurally undervalued at current prices.** Two load-bearing reasons:

1. **Supply shortfall.** Memory (DRAM / HBM / NAND) needs materially more production than is currently on line — present demand is not being fulfilled. Persistent tightness → pricing power → margin/earnings upside the trailing financials do not yet reflect.

2. **Physical-AI demand step-up.** As physical AI (robotics, embodied/edge AI, autonomy) scales, memory content per system rises sharply — a demand vector beyond the current datacenter-HBM cycle that disproportionately benefits the memory makers.

### What the models MUST test (do not accept the above as fact)

- **Is it already priced in?** This is the load-bearing question for Model B / regime. At the current quote, how many years of the shortfall + physical-AI demand are already embedded? If the bull case is fully priced, "undervalued" fails even when the thesis is directionally correct.
- **Cycle position.** Memory is cyclical — any "undervalued" claim depends on where in the DRAM/HBM/NAND cycle we are (early / mid / late) and whether the next down-leg is modeled, not assumed away. Bear case must model the cycle turning.
- **Supply-shortfall evidence in the data.** Utilization, wafer-add / capex timelines, HBM allocation, DRAM/NAND ASP trend — is "needs not fulfilled" visible in pricing power and lead times, or is it narrative?
- **Physical-AI demand timeline.** Concrete, not aspirational — when does embodied-AI memory content actually move MU revenue, and is that inside the valuation horizon (vs Model D optionality territory)?
