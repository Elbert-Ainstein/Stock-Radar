## 2026-06-26 — Structural memory-bull thesis (memory node: MU, SNDK)

Hume's standing view: **memory is structurally undervalued at current prices.** SNDK is the NAND / enterprise-storage expression of the same node thesis. Two load-bearing reasons:

1. **Supply shortfall.** Memory (DRAM / HBM / NAND) needs materially more production than is currently on line — present demand is not being fulfilled. For SNDK specifically, NAND/SSD pricing power and bit-demand are the levers. Persistent tightness → margin/earnings upside the trailing financials do not yet reflect.

2. **Physical-AI demand step-up.** As physical AI (robotics, embodied/edge AI, autonomy) scales, storage and memory content per system rises sharply — a demand vector beyond the current datacenter cycle that disproportionately benefits memory/storage makers.

### What the models MUST test (do not accept the above as fact)

- **Is it already priced in?** Load-bearing for Model B / regime — how many years of the NAND up-cycle + physical-AI demand are embedded in the current quote? Fully priced → "undervalued" fails even if directionally right.
- **Cycle position.** NAND is cyclical (and historically more brutal than DRAM) — "undervalued" depends on cycle phase and whether the next ASP down-leg is modeled. Bear case must model the cycle turning.
- **Supply/demand evidence in the data.** NAND bit-supply growth, enterprise-SSD demand, ASP trend — is the shortfall visible or narrative?
- **Physical-AI demand timeline.** When does embodied-AI storage content actually move SNDK revenue, and is it inside the valuation horizon?
